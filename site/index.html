A safe home for your AI coding agents.

blackthorn turns one small, isolated machine into the place where your agents live. They keep running there, you reach them from your phone or laptop, and each one works on exactly one of your machines, over SSH, one way only.

curl -fsSL https://blackthorn.frakw.work/install.sh | sh

On a dedicated Debian, Ubuntu, Fedora or Arch machine or VM with systemd. Open source, MIT licensed. Works with Claude Code and Codex.

Agents that keep running

Each space runs its agent in the background. Open as many chats as you like from the web UI or, for Claude, from the Claude app. Spaces survive disconnects, restart after crashes and come back after a reboot.

Only the machines you give it

A space is one agent plus the machines you give it. It can reach those and nothing else, enforced by the kernel's firewall, not by asking the model. Your machines cannot connect back to the hub at all.

Read-only, user or root

On each machine a space gets logins of its own: read-only, an ordinary user for its project, and root only for a time you choose, or on approval: each root command waits for you to press Approve. One space at a time has root on a machine.

Keys stay on the hub

Private keys live in root-only files and reach each space only through an agent it cannot read. The keys work only from the hub's address, so a copied key is useless elsewhere.

See everything

A live map of machines and spaces. Every command a space runs is recorded on the hub, out of the space's reach, and in the machine's own system log too.

Built for your phone

The web UI works on a phone: chat with your agents, approve root commands, give a space another machine, or cut a machine off with one tap. Sign-in needs a password and a code, or a passkey.

  1. Install blackthorn on a small dedicated VM. The installer sets up the web UI and, if you like, Tailscale, so only your devices reach it.
  2. Add a machine: paste one line into its authorized_keys, confirm its fingerprint, and let blackthorn set up the logins for its spaces.
  3. Make a space: pick a machine, the agent and how far it may go. Sign the agent in once, then chat.

Install

On the hub, as root or with sudo:

curl -fsSL https://blackthorn.frakw.work/install.sh | sh

It installs the few packages blackthorn needs, downloads thorn and checks it against the release's checksums, installs Claude Code, offers Tailscale, and turns on the web UI. Running it again upgrades blackthorn and leaves your settings alone. Options:

curl -fsSL https://blackthorn.frakw.work/install.sh | sh -s -- --help

Prefer to read it first? View the script, or download a release and check SHA256SUMS yourself.

Requirements

  • A dedicated machine or VM with systemd. Nothing else should run on it.
  • For Claude: a plan with Remote Control (Pro, Max, Team or Enterprise). For Codex: a ChatGPT plan with Codex, or an OpenAI API key.
  • Machines to manage (Linux, for now best supported) reachable from the hub at a fixed address. A Tailscale or Headscale tailnet works well.

Before you trust it

blackthorn is young (early versions, changing often) and tested end to end on every change. Read the threat model: it says plainly what blackthorn protects against and what it does not.
